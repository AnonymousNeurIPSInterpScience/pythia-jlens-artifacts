# R2 — E48's `--rstrip` sensitivity arm, run and stored

## WHAT WAS RUN
The `--rstrip` arm of E48, which `repro/exp/e48_crossover.sh:5-7` declares as the disclosed
sensitivity arm and which `results/e48_crossover_410m.json` describes in prose as run, was executed
unmodified via `RUN_RSTRIP_ARM=1 bash repro/exp/e48_crossover.sh`. That script first re-runs the
unstripped primary (`experiments/t48_crossover.py --device cpu --n-derangements 5 --n-boot 10000`),
then runs `experiments/t48_crossover.py --device cpu --rstrip --out
results/e48_crossover_410m_rstrip.json`. The stripped arm scores the same 8 corpus operators x 3
seeds, 5 layer-derangements per cell, the identity/logit arm and a norm-matched random arm, at the
readout token obtained after `.rstrip()` on the prompt.
