# E60 -- fitter cross-implementation and thread-count determinism

## WHAT WAS RUN

Two Jacobian fitters -- the vendored released one (`jlens.fitting`, "anchor") and the repo's
`fastfit` -- were run on the same 8 prompts of the same model at torch thread counts 1, 4, 8, 10 and
12. At each thread count the script recorded the maximum absolute disagreement between the two
implementations, the relative disagreement, and each implementation's disagreement with **itself**
measured against its own run at the base thread count. A repeat run at a fixed thread count was
compared bit-for-bit (C1), and the token length of every fitting prompt was recorded against
`skip_first` (C2). No read scoring, no eval sets, no aggregation is involved.
