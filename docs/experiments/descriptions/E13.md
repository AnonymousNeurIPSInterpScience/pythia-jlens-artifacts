# E13 — stable rank of the fitted operator under penultimate versus final target layer

## WHAT WAS RUN

For four models, the per-source-layer stable rank of the penultimate-target lens and of the
final-target lens was tabulated, and for each model the max, the mean and the penultimate/final
ratio of both were stored. The file states that everything except `target_layer` was held fixed. No
eval set is read and no pass@k is computed.
