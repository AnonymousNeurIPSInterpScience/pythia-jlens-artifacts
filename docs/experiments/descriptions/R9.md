# R9 — the `min` statistic scored against its own layer-derangement null

## WHAT WAS RUN

No new measurement. `tools/r9_permutation_calibrated_min.py` read
`results/e48_crossover_410m_rstrip.json`, which stores per corpus and per aggregation the real
operator's admitted-set mean and 15 layer-derangement draws (5 derangements × 3 seeds). For each of
the eight corpora it computed the real value's rank within its own 15-draw null, the one-sided
empirical p as `(1 + #{null ≥ real}) / (1 + 15)`, and a z-score against the null's mean and SD.
The same was computed under `persist`.
