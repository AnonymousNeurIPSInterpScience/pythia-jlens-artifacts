# P0 — process-pool port of `t52_factorial.py`

## WHAT WAS RUN
`experiments/t52_factorial.py` was given a `--workers` flag; the per-cell scoring body was moved to
a module-level function run by a `multiprocessing.Pool` whose workers load the model and operators
themselves, while the parent keeps prefix construction, the item/pair tables, and all aggregation.
The 30 `(fit corpus/read rung block, prefix seed)` cells were then scored with `--workers 3` at the
unstripped readout, writing `results/e52_factorial_410m_pooled.json` and
`results/e57_factorial_cells_410m_pooled.json`. The pooled matrix was compared cell-by-cell to the
stored serial matrix in `results/e52_factorial_410m.json`. Three further full-grid runs at
`--workers` 1, 2 and 8 were executed later, each with `--rstrip`, writing
`results/e52_factorial_410m_rstrip_w{1,2,8}.json`.

## PRE-REGISTERED RULE (verbatim)
> * **ACCEPT:** the pooled run reproduces the serial run's stored matrix at **`max_abs_diff = 0.0`
>   across all 128 cell values**, and wallclock falls by at least 3x.
> * **REJECT:** any non-zero difference. **STOP.** A parallelisation that changes a number is a bug,
>   and shipping it would put a scheduling artifact inside the paper's headline. Do not "investigate
>   the tolerance" — there is no tolerance. The same computation in a different order over the same
>   fp32 inputs must give the same bits here, because nothing is reduced across cells.

Registration source: `docs/experiments/preregs/P0_t52_parallel_port.md` §"PRE-REGISTRATION — the rule,
verbatim", quoting `POSTREVIEW_EXPERIMENTS.md` §3 item P0. The same text is stored in the
results file at `results/e52_factorial_410m_pooled.json -> decision_rule_verbatim.P0`:
> "ACCEPT: the pooled run reproduces the serial run's stored matrix at max_abs_diff = 0.0 across all 128 cell values, and wallclock falls by at least 3x. | REJECT: any non-zero difference. STOP. Do not \"investigate the tolerance\" -- there is no tolerance."

Git timestamp of the registration: commit `a4fc687`, `2026-08-19T21:41:43-07:00`
("PREREG P0, R1, R2, R3, R4, R4b, R5 — the post-review slate, registered before any code moves").
