# R1 — 8x8 fit x read grid re-scored at the stripped readout token

## WHAT WAS RUN
`experiments/t52_factorial.py` was given a `--rstrip` flag that applies `.rstrip()` to the eval
prompt before tokenisation and before `readout_position(tok, name, p)` is called on the same string.
The full 8 fit-corpus x 10 read-rung grid (30 pooled cells over 3 prefix seeds) was re-scored with
`--device cpu --workers 6 --rstrip`, writing `results/e52_factorial_410m_rstrip.json` and the
per-cell draws `results/e57_factorial_cells_410m_rstrip.json`. `experiments/t57_grid_variance_ci.py`
was then run on those cells, writing `results/e57_grid_variance_ci_rstrip.json`. The operators, band,
K grid, admitted sets, seeds and bootstrap/permutation counts were held at the published values; the
unstripped files were not overwritten.
