# E56 — enumeration of candidate predictors across seven results files

## WHAT WAS RUN

`experiments/t56_predictor_registry.py` reads seven stored results files and writes one row per
candidate predictor found in them. Each row records the predictor name, its source file, the
outcome variable it was correlated against, the replication unit, `n`, the full-sample `r`, the
worst leave-one-out `r`, which item was dropped to produce that worst value, the criterion the
source file recorded for it, and a pass/fail flag read from that criterion. Rows are additionally
tagged `candidate`, `control`, `duplicate`, or `different-outcome`. The file records
`"recomputes_not_remeasures": true`; no model is loaded and no correlation is re-adjudicated.
