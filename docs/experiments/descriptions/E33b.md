# E33b — storing the E33 per-corpus t statistics

## WHAT WAS RUN

`experiments/t33b_store_tstats.py` read `results/e33_logit_baseline_410m_v2.json`, took the
logit-lens `persist` 5-admitted-set mean as a constant `L` and each corpus's stored asymptote mean
and seed SD, and computed a one-sample t statistic per corpus,
`t = (Y_inf(P) - L) / (seed_sd(P) / sqrt(3))` with `df = 2`. It compared each `|t|` to the
two-sided 5% critical value at df = 2 and wrote the result with a `provenance` stamp. No model was
loaded, no operator was fitted, and no read was re-scored; the file's own header records
`recomputes_not_remeasures: true`.
