# E51 — corpus x concept-set variance decomposition of the stored read ladders

## WHAT WAS RUN

`experiments/t51_interaction_variance.py` read 30 stored ladder files (15 from
`results/ladder410/`, 15 from `results/ladder1b/`) and recomputed a balanced two-factor variance
decomposition of read AUC over (eval set, corpus) with the seed block as the replication unit,
after averaging over the N axis at N >= 75. No model was loaded and no lens was refitted; the file
records `"recomputes_not_remeasures": true`. The decomposition was run for two scales (410M, 1B)
and, at each scale, for the five admitted eval sets and for all six sets. Four sums-of-squares
fractions, an F test against the seed residual, a label-permutation null and an audit of a
previously-quoted "4614x" multiplier were written to `results/e51_interaction_variance.json`.

>   C1 SUMS TO ONE   the four fractions must sum to 1 within 1e-9. A balanced decomposition is an

>                    and interaction sums of squares EXACTLY unchanged (they are means over

>                   the residual scale. Reported as the interaction fraction under 200 label
>                   permutations: the observed value must sit outside that null.
> ```
