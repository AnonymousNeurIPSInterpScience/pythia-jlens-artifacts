# E36 — the Q-ladder: read-distribution prefixing at thirteen rungs, 410M

## WHAT WAS RUN

Five stored Jacobian operators (`e28_<corpus>_410m_n400_s0.pt`), the logit lens (`J = I`), and an
arm named `shuf` were scored on the five admitted concept eval sets. `shuf` is built at
`experiments/t36_qladder.py:144–145` as `JSHUF = {l: JP["Pile-CC"][q] for l, q in zip(BAND, perm)}`
with `perm = derangement(BAND, 7000)`. The two 2026-08-20 files add five `shufown|<corpus>` arms,
built at `t36_qladder.py:146` from each corpus's own operator under the same permutation. Each eval
item was scored thirteen times: once with no prefix (rung `Q0`) and once per Q-corpus with a
128-token prefix drawn from that corpus prepended to the item's own prompt, with three prefix draws
(`prefix_seeds = [0, 1, 2]`) per rung. Readout positions are computed on the item alone and offset
by the prefix length (`t36_qladder.py:300`, `:344`). The x-axis stored against each rung is `containment_k32` read from
`results/e48b_exposure_growth.json`. Three result files exist: the 2026-08-15 run, a 2026-08-20
`--rstrip` run, and a 2026-08-20 unstripped re-run through the same 2026-08-20 code.

## PRE-REGISTERED RULE (verbatim)

From `docs/experiments/preregs/superseded/PREREG_E36_QLADDER.md`:

> **PRIMARY**
>
> **The one number: the containment level `c*` at which the J-lens read AUC curve crosses the logit
> lens's.** Reported per fitting corpus P (five values), with the crossing located by linear
> interpolation between adjacent rungs and bootstrapped over the 3 prefix seeds.
>
> Secondary: the **slope** `d(AUC)/d(containment)` for each transport. S3's claim in its weakest
> testable form is that the J-lens slope is steeper than the logit lens's.

> **DECISION RULE — fixed before running, not reinterpretable**
>
> - **ACCEPT S3** if, for ≥3 of the 5 fitting corpora, the J-lens curve crosses below the logit-lens
>   curve at some rung, **AND** the crossing survives leave-one-rung-out, **AND** control C3
>   (capability) has not collapsed at or before the crossing rung.
> - **REJECT S3** if the two curves remain parallel within their seed intervals across the whole
>   ladder — i.e. shift degrades *both* lenses equally. **This is the publishable null**: the fitted
>   operator is no more shift-fragile than the unfitted one, and the averaged derivative is robust.
> - **UNCLEAR** if capability (C3) collapses at or before any crossing, because lens failure and
>   model failure are then not separable. **Stop. Do not re-pick Q to manufacture a crossing.**
>
> **A crossing that appears only under `min` aggregation does not count.** `min` is disqualified
> (CLAUDE.md §6.0) and is reported but never votes.

Registration source: `docs/experiments/preregs/superseded/PREREG_E36_QLADDER.md`.
`e36_qladder_410m.json -> prereg` stores the string
`"pythia/docs/experiments/preregs/superseded/PREREG_E36_QLADDER.md (2026-08-13, before any E36 number existed)"`;
`e36_qladder_410m_rstrip.json -> prereg` and `_c1arm -> prereg` store
