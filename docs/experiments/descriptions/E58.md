# E58 -- algebra and measurement checks on E45, E36 and the containment chain

## WHAT WAS RUN

`experiments/t58_algebra_audit.py --device cpu` recomputed three quantities from artifacts already
on disk. (A) E45's post-norm predictor was recomputed in four orientations of the final-LayerNorm
Jacobian `G` -- `none` (pre-norm), `coded_G_transpose` (`WU @ G.T`, as `t40:165` computes it),
`correct_G` (`WU @ G`), and `symmetrised` -- each scored against the same 0.5 threshold with
leave-one-out over eval sets and over corpora. (B) E45's C2 null control was rebuilt with five
independent norm-matched random `Delta` (one per corpus) in place of the single shared `Delta` the
original used, through the identical pipeline. (C) The fraction of E36's prefix documents for each
corpus that also appear in that corpus's own N=400 seed-0 fitting pool was counted, per prefix seed.
