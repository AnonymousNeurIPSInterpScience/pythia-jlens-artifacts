# E35 -- n-gram containment of candidate corpora against the Pythia training stream

## WHAT WAS RUN

A Bloom filter was built over the k-grams of every candidate corpus `Q` for k in {8, 13, 20, 32}
at window 128, the token stream was probed position by position, and Bloom hits were verified
exactly against a sorted array; containment is `n_found / n_distinct_kgrams` per (Q, k). Two
correctness gates ran first: G1, that the corpora tokenise identically to the released 20B
tokenizer, and G2, that the vocabulary fits `uint16`. `k` was then selected by the stored rule.
Four result files exist under this experiment id: two synthetic-stream smoke runs, one merge-mode
run over one shard's worker bitmaps, and one further synthetic-stream run over an enlarged corpus
list.

Note on the id: `PLAN.tex` §"What is CUT, and why" uses the label "E35" for a
different proposed experiment ("one scale (1B) $\times$ the same 5 corpora $\times$ 3 seeds at
**fixed $N{=}200$**"). The four result files documented here carry
`"experiment": "E35 / M1 — n-gram containment against the Pythia stream (inverted query)"` and
`"prereg": "...PREREG_E36_QLADDER.md, section E35"`.

## PRE-REGISTERED RULE (verbatim)

> ## PRIMARY
>
> Containment `c(Q)` for every candidate Q, at the selected k.
>
> ## DECISION RULE — k is selected by a rule fixed in advance
>
> **Choose k as the largest value in {8, 13, 20, 32} for which the candidate Q's span a containment range ≥ 0.3.**
>
> - If **no k** achieves a 0.3 range, M1 cannot rank these Q's → **the x-axis falls back to the ordinal rung and E36 runs with a categorical axis, disclosed as such.**
> - If **k=8 saturates** every Q at c ≈ 1.0, that is reported, not hidden.

> ## CONTROLS
>
> | id | control | must produce |
> | **M1-C1** | a known Pile component (Pile-CC windows, already ID by construction) | **high** containment — if a corpus we *know* is in the Pile scores low, the index is broken |
> | **M1-C2** | random-token documents at matched length | containment ≈ 0 |
> | **M1-C3** | post-2020 text | must score **below** M1-C1. If not, either the date argument or the index is wrong |
> | **M1-C4** | one shard vs twenty | containment on 1/20 of the stream must be a strict **lower bound** on containment over 20/20 |

Registration source: `docs/experiments/preregs/superseded/PREREG_E36_QLADDER.md`, section
"PRE-REGISTRATION — E35, the M1 containment index (E36's x-axis)".

Thresholds as coded: `M1_C1_fires` requires the planted corpus' containment `> 0.1` at every k
(`experiments/t35_containment.py:326`); `M1_C2_fires` requires the random control `< 0.01` at every
k (`:320`); `k_selected` is `max{k : range >= 0.30}` over corpora whose name does not start with
`_CONTROL` (`:307-313`).
