# E44 — D_read, an operator-distance quantity tested against the per-corpus read gap

## WHAT WAS RUN

Activations were recorded at the readout position of every scorable item in the anchor eval battery,
at each of the 13 band layers of `pythia-410m-deduped`. For each of the five stored N=400 seed-0
operators, four quantities were computed as a median over the band: `dread_vs_I`, `dread_vs_Jeval`,
`dact_vs_I`, and `dread_random_rows_vs_I`. Each was correlated (Pearson, n=5 corpora) against
`gap_vs_logit`, the per-corpus read asymptote from `e33_logit_baseline_410m_v2.json` minus that
file's logit constant, with a leave-one-corpus-out recomputation for each of the five corpora.

The stored definitions, from `experiments/t39_dread.py`:

- `dread(Ja, Jb, W)` = `E||W (Ja-Jb) h||^2 / E||W Ja h||^2`, median over the band, with `W = W_U`
  restricted to the concept token ids (`Wc`).
- `dact(Ja, Jb)` = the same ratio with `W` omitted.
- `dread_random_rows_vs_I` uses `Wr`, a random row-subset of `W_U` of the same size
  (`torch.Generator().manual_seed(0)`).

>             size. If that predicts equally well, "concept rows" is doing no work.
