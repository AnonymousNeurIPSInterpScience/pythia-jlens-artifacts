# E55 — leave-k-out recomputation of the fit-axis / read-axis variance shares, and the same decomposition on the E36 5×5

## WHAT WAS RUN

`experiments/t55_matrix_robustness.py` reads stored results files and recomputes the two-way
variance decomposition of the 8×8 fit × read matrix. The file records
`"recomputes_not_remeasures": true`; no model is loaded and no lens is refitted. It computes the
decomposition on the full 8-corpus panel, on all 8 leave-one-corpus-out subsets, and on all 28
leave-two-corpus-out subsets, under both aggregations. It also computes the same decomposition on
the 5×5 fit × read matrix stored in `e36_qladder_410m*.json`, per prefix-seed draw and
seed-averaged, with and without the diagonal cells. Two controls are computed. The script was run
twice: once on the unstripped E52/E36 inputs and once on the stripped ones.
