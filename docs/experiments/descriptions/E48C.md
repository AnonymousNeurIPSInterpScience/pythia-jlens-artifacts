# E48c — correlation between measured containment of the fitting corpus and the `persist` read, with the seed block as the replication unit

## WHAT WAS RUN

Two stored files were joined: for each of E48's eight fitting corpora, the `persist` admitted-mean
read and its across-seed SD were taken from `results/e48_crossover_410m.json`, and the k=32,
20-of-20-shard containment value was taken from `results/e48b_exposure_growth.json`. Pearson and
Spearman correlations between containment and read were computed over all eight corpora and over the
seven excluding Github. A tier contrast (four in-stream vs three OOD, Github excluded) was computed
with the corpus as the replication unit, and one named pair (`OOD_arXiv_2023` vs `Wikipedia_en`) was
compared with the seed block as the replication unit. Three controls were evaluated. No forward pass
was run.
