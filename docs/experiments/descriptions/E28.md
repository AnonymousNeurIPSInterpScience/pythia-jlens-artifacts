# E28 — read ladder over fitting corpus and fitting sample size

## WHAT WAS RUN

Jacobian operators were fitted on `pythia-410m-deduped` for five Pile components at six fitted
sample sizes (25, 50, 100, 200, 400, 800) in three disjoint seed blocks, and the anchor read
battery was scored from those operators at 16 reconstructed values of `N` (nested prefixes).
The same procedure was run on `pythia-1b-deduped` at seven checkpoints of `N`
(10, 25, 50, 75, 100, 150, 200). Each `(corpus, seed)` cell is one JSON file storing, per `N` and
per eval set, four aggregations of read AUC. Downstream summaries (asymptotes, seed SDs, spread)
were computed by `experiments/t53_ladder_summary.py`.

## PRE-REGISTERED RULE (verbatim)

The spec `docs/experiments/preregs/E28_read_ladder.md` states:

> `docs/experiments/preregs/superseded/PREREG_PYTHIA_T7_v2.md` governs the confirmatory cells; E28's own primary
> ("do the per-corpus asymptotes separate?") was fixed with amendments A1/A2 before scoring.

No accept/reject rule text for E28's own primary is present in
`docs/experiments/preregs/superseded/PREREG_PYTHIA_T7_v2.md`; that file registers the T7 lens comparison.

A verbatim three-branch rule for E28's own primary **is** present in `SPINE.tex`,
§"E28 — the two-parameter fit. PRE-REGISTRATION, fixed before any number", subsection "DECISION
RULE on the science" (lines 331–342):

> **ASYMPTOTES SEPARATE** (per-corpus $Y_{\infty,P}$ differ beyond their CIs)
> $\Rightarrow$ corpus identity sets a floor more data cannot fix. **S3 is real and $\Dact$ has a
> target to predict.**
> **ASYMPTOTES COINCIDE, slope significant** $\Rightarrow$ $\epsilon$ is a sufficient statistic;
> corpus identity acts only through dispersion. **S2 explains S3.**
> **NEITHER** (no slope, no separation) $\Rightarrow$ the eval set is insensitive to the operator.
> **STOP. Do not re-pick the eval set to manufacture sensitivity.**

The same section fixes the metric admission rule verbatim:

> A metric enters the pooled slope estimate **only if all three hold**:
> 1. **Signal exceeds noise.** Its range across the $N$ grid at fixed corpus exceeds $2\times$ its
>    within-cell seed standard deviation. …
> 2. **Its named control fires**, at the largest $N$, with a paired CI excluding zero — $\JP$ beats
>    $\Jsh$ for reads and writes; `rand_match` sits below $\JP$ for ablation.
> 3. **Non-degenerate.** Not floored at zero, not saturated at ceiling, in $\ge4$ of the 5 corpora.

Amendments A1 and A2, both dated 2026-08-13 in that file, are §"E28 — AMENDMENT A1, 2026-08-13.
Written after the fits, before any analysis" and §"E28 — AMENDMENT A2, 2026-08-13. THE
ADJUDICATION."

Registration source: `docs/experiments/preregs/superseded/PREREG_PYTHIA_T7_v2.md` (confirmatory-cell guard only)
and `SPINE.tex` §E28 / §A1 / §A2 (the primary's three-way rule and its amendments).
