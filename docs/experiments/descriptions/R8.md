# R8 — the 410M ladder's range over N, at both readouts, against the between-corpus spread

## WHAT WAS RUN

`tools/r8_ladder_flatness.py` read the 15 CPU-scored 410M ladder cells at each readout —
`results/ladder410_cpu/` (unstripped) and `results/ladder410_cpu_rstrip/` (stripped) — and, for
each corpus, computed the seed-mean read curve over the reconstructed N grid, the asymptote
(mean over N ≥ 75), the seed SD, and the range over N expressed both absolutely and in seed-SD
units. It then formed the between-corpus spread and the ratio of the largest per-corpus range over
N to that spread, under `persist` and `min`. It also stores four controls, including a
reproduction cell re-scored into `results/r8_c1_unstripped/`.

This tool uses the INTERSECTED grid, which is the clean estimand."
