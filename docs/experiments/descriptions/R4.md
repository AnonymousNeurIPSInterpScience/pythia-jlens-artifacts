# R4 — twelve recomputations of numbers already on disk

## WHAT WAS RUN

Twelve labelled items (R4a–R4l), each a recomputation from artifacts already on local disk, run by
`tools/r4_recomputes.py` into `results/r4_corrections.json`, with two items given their own files:
`tools/r4e_control_power.py` → `results/r4e_control_power.json` (an enumeration of every control
row in every results file, classified by whether it had a gate that could fail) and
`results/r4g_e28_provenance.json` (a repair pass over the 166 E28 operator sidecars). Each item was
compared against a value taken from `POSTREVIEW_EXPERIMENTS.md` ("the slate") and marked
agreeing or disagreeing.
