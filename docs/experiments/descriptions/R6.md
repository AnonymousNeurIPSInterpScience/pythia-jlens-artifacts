# R6 — within-source resampling of two fitting corpora

## WHAT WAS RUN
Two in-stream sources (Pile-CC, Wikipedia_en) were each split into four disjoint document blocks;
one operator was fitted per block at N=200, giving 8 operators. All 8 were read against the fixed
five-set battery at the stripped readout, and the read variance was decomposed into a
between-source and a within-source sum of squares. The fit and the first scoring pass ran on a rented GPU box
(`results/r6_within_source_410m.json`; `provenance.env` records Linux, torch 2.11.0+cu128, hostname
`00253a3bcb1c`; the spec's §RESULT names an RTX 4090); the same stored operators were then re-scored
on the laptop CPU (`results/r6_within_source_410m_cpu.json`). Three controls were
computed in both passes: pairwise document disjointness, a 2000-draw shuffled-source-label null,
and a per-operator layer-derangement floor.

## DISAGREEMENTS RECORDED, NOT RESOLVED
1. **`min` between-source share differs between the two arms of the same experiment.** GPU file
   `0.9894360450808499`; CPU file `0.9886393225473908`
   (`-> by_aggregation.min.between_source_share`). The `persist` values differ in the 7th decimal
   (`0.9722598722750339` vs `0.9722603429765596`).
2. **Which `min` value the prose cites.** `docs/experiments/preregs/R6_within_source_resampling.md`
   §PRIMARY writes "(0.9886 under `min`)" and its §RE-ADJUDICATED table writes `min` = **0.9886**;
   `docs/context/AGGREGATION_POLICY.md` line 82 writes "R6 between-source share | 0.9723 | **0.9886**";
   `docs/context/RESULTS_TAXONOMY.md` §5.11 writes "0.9886 under `min`". The GPU results file, which the
   spec names first in §RESULT, stores `0.9894360450808499`. Both numbers and both paths are given
   here; no adjudication.
3. **Stored `prereg_sha256` vs the spec file on disk.** Both results files store
   `prereg_sha256 = "bc70dec33c9270b782dc4a3edfbf5ad05fd9bb6e1879eda22dbb61e34e07030d"`. The
   current `docs/experiments/preregs/R6_within_source_resampling.md` hashes to
   `7c8d4c6438dcc18f4c136805ab97c68ffc997ba07acbf40ab6986ed2c99afbea`, which is also the value
   recorded at `results/postreview_completion.json -> items[item="R6"].prereg_sha256`. The spec's
   git history shows two post-run commits (`32f753b`, `b07615e`).
