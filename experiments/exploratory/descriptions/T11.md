# T11 — fit-corpus variation: wikitext versus a task-adjacent refit, at pythia-70m

## WHAT WAS RUN

`experiments/t11_fit_distribution.py` scored, for each eval set `E`, three arms on the same items:
a logit-lens floor (`transport_logit`, no fitting), a J-lens fitted on 40 wikitext prompts, and a
J-lens fitted on 40 prompts drawn from the anchor's own prompts for `E` (`corpus = "eval:<E>"`, the
refit-on-target cell). `skip_first` was overridden to 2 because most anchor eval prompts are shorter
than the default skipped-position count. The difference `TASK.auc − wikitext.auc` was stored per set.
Two results files exist at the same model and settings: an initial run over `typo` and
`multilingual`, and a later backfill run over `multihop`, `multilingual` and `typo`.
