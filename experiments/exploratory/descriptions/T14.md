# T14 — Jacobian dispersion by relative depth across six Pythia models

## WHAT WAS RUN

`experiments/t14_dispersion_ladder.py` read the six penultimate-target lens provenance files matching
`results/lenses/ladder/lens_*_db128_pen_provenance.json`, took the `jacobian_dispersion` block already recorded in
each at fit time, and re-indexed the per-layer dispersion profile by **relative** depth
`l / (n_source − 1)` at seven fixed points. For each model it stored the interpolated dispersion, the
quantity `1 − 1/sqrt(1+disp)`, and the interpolated heavy-tail ratio at those seven points, plus the
dispersion range inside the band `[round(0.38·n_layers), min(round(0.92·n_layers), n_source−1)]`.
Across models it stored the min, max and max/min of the interpolated dispersion at each relative
depth. No model was loaded, no forward pass was run, no GPU was used.
