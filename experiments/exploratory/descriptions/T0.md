# T0 — port gate for the vendored Jacobian-lens fitter on GPT-NeoX/Pythia

## WHAT WAS RUN
`experiments/t0_smoke.py` was executed once per model on `EleutherAI/pythia-{70m,160m,410m,1b}-deduped`, CPU, float32, on three hard-coded prompts stored in the script (`experiments/t0_smoke.py`, `PROMPTS`). The script resolves an explicit `Layout` for GPT-NeoX, records eight named gates G1–G8, calls the vendored `jlens.fitting.fit`, computes per-layer singular-value statistics of each fitted `J_l`, reads out the J-lens and the logit lens at the middle fitted layer on one held-out prompt, and saves/reloads the lens to check the round trip. Each run writes one results JSON and one `.pt` lens.
