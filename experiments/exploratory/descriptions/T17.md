# T17 — re-scoring the read battery under four layer aggregations, 160M and 410M

## WHAT WAS RUN
The six-set anchor read battery was re-scored from one forward pass per prompt at two scales, with
no refit. Three transports were scored — `logit` (J = I), `jlens`, and `shuffled` (the fitted
operator with layer index permuted by a fixed derangement) — and the per-layer pass@k ranks were
summarised under four aggregations: `min` (min over layers, the anchor's metric), `best1L` (best
single layer), `mean` (mean over layers), and `persist` (rank ≤ k at ≥ K band layers, K a fraction
of band depth, `persistence_kfrac = 0.5`). For each set the file stores the `jlens − shuffled`
difference ("layer_specific") and the `shuffled − logit` difference ("generic") under all four
aggregations, and assigns the set a stability verdict. Prompts were `.rstrip()`-ed
(`experiments/t17_reaggregate.py:66`).

## PRE-REGISTERED RULE (verbatim)
Stored in both results files at `-> decision_rule`:

> "sign of (jlens - shuffled) stable across all four aggregations => the set's classification stands; otherwise AGGREGATION-DEPENDENT and excluded from any claim"

The script docstring (`experiments/t17_reaggregate.py`) states it as:

> DECISION RULE, fixed in advance (RESEARCH_NOTES sec13 E18):
>   If the SIGN of the layer-specific component (jlens - shuffled) is stable across all
>   aggregations on a set, that set's classification stands. Otherwise it is reported as
>   AGGREGATION-DEPENDENT and excluded from any claim.

Registration source: the script docstring, which cites `RESEARCH_NOTES §13 E18`. In
`RESEARCH_NOTES.tex` the §backlog table (line 2041) lists **E17** as
`\texttt{t17} re-aggregation` and **E18** (line 2044) as `\texttt{t18} $n$ sweep`; the results file's
own `experiment` string reads `"T17 / E18 — re-score reads under non-existential aggregations"`. Both
labellings are recorded; not adjudicated here. No file in `docs/archive/prereg/` covers T17.

No pre-registered threshold on `n_win` is stored in either file.
