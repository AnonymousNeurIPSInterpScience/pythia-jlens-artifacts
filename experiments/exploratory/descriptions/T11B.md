# T11B — how many items of each anchor eval set are long enough to fit an operator on

## WHAT WAS RUN

The seven anchor item sets were tokenised with the pythia-410m tokenizer and each item's prompt
length in tokens was compared against the fitter's minimum, `min_seq_len_required` = `skip_first + 2`
= 18. For each set the file records the item count, the number of items at or above that length, the
resulting percentage, and the set's median prompt length in tokens. No model forward pass, no fit,
no read.
