# T13 — five transports scored against the logit lens on six eval sets, at three scales

## WHAT WAS RUN

`experiments/t13_transport_controls.py` scored six transports through one readout path, on the same
items and the same layers: `logit` (`T = I`), `jlens` (`T = J_l`), `shuffled`
(`T = J_{π(l)}` for a fixed-point-free permutation π of the layers), `spec_random`
(`T = U' S V'^T` with `S` the singular values of `J_l` and `U'`, `V'` random orthogonal), `rank1`
(`T = s₁u₁v₁^T`) and `scaled_id` (`T = cI`, `c = ‖J_l‖_F/√d`), the last declared in the script as a
self-test rather than a control. For each transport and each of six anchor eval sets the run stored
the paper-form AUC, the README-form AUC and the median best rank, then counted how many sets each
transport beat `logit` on, and decomposed the J-lens advantage into a `generic` part
(`shuffled − logit`) and a `layer_specific` part (`jlens − shuffled`). One run per model at 70m,
160m and 410m.
