# T19 — skip_first sweep: 0 vs 4 vs 16 on the 410M read battery

## WHAT WAS RUN
Three Jacobian lenses were fitted on pythia-410m-deduped at n = 200, differing only in
`skip_first` ∈ {0, 4, 16} — the number of leading sequence positions excluded from the per-prompt
position average. Each was then scored on all six anchor eval sets with three transports (`logit`,
`jlens`, `shuffled`) under four aggregations (`min`, `best1L`, `mean`, `persist`). Layer-0 and
last-layer Jacobian dispersion were recorded for each fit. The pre-registered comparison is the
spread in `n_win` vs the logit lens under `best1L` across the three skip values.

## PRE-REGISTERED RULE (verbatim)
Stored at `results/t19_skipfirst_410m.json -> decision_rule` and `-> primary_outcome`:

> "n_win (best-single-layer) spread <=1 => immaterial; >=2 => live parameter"
> "n_win vs logit under BEST-SINGLE-LAYER AUC"

The script docstring (`experiments/t19_skipfirst_sweep.py`) states:

> PRE-REGISTERED (RESEARCH_NOTES sec13 E17):
>   PRIMARY OUTCOME  n_win vs the logit lens under BEST-SINGLE-LAYER AUC (not min-over-layers,
>                    per the E18 finding that min is existential and defective), plus disp(L0).
>   DECISION RULE    if n_win differs by <=1 across all three values, skip_first is immaterial on
>                    Pythia and 16 stays for continuity. If it differs by >=2, skip_first is a
>                    live parameter and D3 must be re-registered.
>   CONTROLS         the layer-shuffled J at each value.
>   MODEL            410m -- already fully observed, so nothing is burned.

Registration source: the script docstring, citing `RESEARCH_NOTES §13 E17`. In
`RESEARCH_NOTES.tex` the §backlog table (line 2048) lists **E19** as
`\texttt{t19} \texttt{skip\_first}` and **E17** (line 2041) as `\texttt{t17} re-aggregation`; the
results file's `experiment` string reads `"T19 / E17 — skip_first sweep 0 vs 4 vs 16"`. Both
labellings are recorded; not adjudicated here. No file in `docs/archive/prereg/` covers T19.
