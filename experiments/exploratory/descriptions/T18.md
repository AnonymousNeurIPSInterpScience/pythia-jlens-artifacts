# T18 — n-sweep of operator estimation error against the sqrt(dispersion/n) law, 410M

## WHAT WAS RUN
Nested-prefix Jacobian fits were produced on pythia-410m-deduped at n ∈ {10, 25, 50, 100, 200}
(prompts[:n], so the sequence is monotone in data), plus a reference fit at n = 400. For each of the
22 source layers, the measured relative error of `J_hat_n` against `J_hat_400` was recorded at each
n, the log-log slope of that error against n was fitted with the n = 400 point excluded, and the
slope was tested against the interval [−0.6, −0.4]. The analytic prediction `sqrt(dispersion/n)` was
stored alongside the measurement at every (layer, n). Two reference-free diagnostics were computed
per layer as well: split-half disagreement and odd-even disagreement.

## PRE-REGISTERED RULE (verbatim)
Stored at `results/t18_n_sweep_410m.json -> decision_rule`:

> "ACCEPT iff the log-log slope lies in [-0.6,-0.4] at EVERY layer"

and at `-> declared_bias`:

> "J_ref at n=400 is the reference, so n=400 is degenerate and excluded from the fit; reference-free split-half / odd-even are reported alongside"

The script docstring (`experiments/t18_n_sweep.py`) states:

> PRE-REGISTERED (RESEARCH_NOTES sec13 E19):
>   PRIMARY OUTCOME  log-log slope of measured relative error against n, per layer.
>   DECISION RULE    the law predicts slope -0.5. ACCEPT if the fitted slope lies in
>                    [-0.6, -0.4] at EVERY layer. Otherwise the law does not describe this
>                    estimator and S2's backbone must be replaced with an empirical curve.
>   DECLARED BIAS    using J_hat_400 as the reference makes the n=400 point degenerate, so it is
>                    EXCLUDED from the fit. This is the same circularity that invalidated T9's
>                    subspace measure (1.00 at n=200 IS the reference), which is why the
>                    reference-free diagnostics below are run alongside.

Registration source: the script docstring, citing `RESEARCH_NOTES §13 E19`. In
`RESEARCH_NOTES.tex` the §backlog table (line 2044) lists **E18** as
`\texttt{t18} $n$ sweep` and **E19** (line 2048) as `\texttt{t19} \texttt{skip\_first}`; the results
file's `experiment` string reads `"T18 / E19 — does eps = sqrt(disp/n) hold for the averaged
Jacobian?"`. Both labellings are recorded; not adjudicated here. The results file stores
`prereg: null`, and the docstring's closing line reads "EXPLORATORY unless --prereg is cited". No file
in `docs/archive/prereg/` covers T18.
