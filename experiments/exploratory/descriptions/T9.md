# T9 — n-convergence of the fitted operator versus the task metric, at three scales

## WHAT WAS RUN

`experiments/t9_n_convergence.py` fitted a Jacobian operator at each of a nested sequence of prompt
counts `n`, using the same prompt prefix each time so the sequence is nested (`J_n` and `J_ref` share
prompts). For every `n` and every source layer it recorded spectral quantities (`stable_rank`,
`effective_rank`, `top_sv`, `fro`, `dispersion`, `heavy_tail_ratio`) and three comparisons against
the reference operator fitted at the largest `n` in the sweep (`cos_to_ref`, `rel_op_dist_to_ref`,
`subspace_cos_top_r_vs_ref`, the last over the top-`r = 8` left-singular subspaces). In the same run
it scored the anchor `multihop` pass@k task metric at each `n`. Three separate runs: pythia-70m
(ns 1–100, CPU), pythia-160m and pythia-410m (ns 1–200, CUDA).
