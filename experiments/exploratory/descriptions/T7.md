# T7 — transport comparison (logit lens vs J-lens) on the anchor's six evaluation sets, plus a paired item bootstrap

## WHAT WAS RUN
Two scripts. `experiments/t7_lens_comparison.py` was run once per model on `EleutherAI/pythia-{70m,160m,410m}-deduped` with the matching N=200 lens, CPU/float32. For every item in each of the anchor's six released evaluation sets it takes the prompt, applies `.rstrip()`, reads the residual at the per-set readout position through every fitted source layer under two transports (`T = I`, the logit lens, and `T = J_l`, the J-lens), takes the **minimum rank over layers and over synonyms** for each intermediate, and forms pass@k for k ∈ {1, 2, 5, 10, 25, 100} plus a normalized trapezoidal AUC over log k. `experiments/t7_bootstrap_audit.py` re-runs the identical readout on the same models, lenses, layers and items, retains the per-item pass@k fraction vectors, and resamples item indices 10,000 times with seed 0 — one draw applied to both transports — to produce a 95% percentile CI on each per-set AUC delta and a bootstrap distribution of `n_win`. A smoke run of the first script on 30 multihop items at 410m is also stored.
