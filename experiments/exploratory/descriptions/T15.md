# T15 — shuffle diagnostic: per-layer read AUC for jlens, layer-deranged J, and the logit lens

## WHAT WAS RUN
Two quantities were computed from one fitted 410M lens. (A) Pairwise cosine similarity between the
flattened per-layer Jacobians `J_l`, and the cosine of each `J_l` with the identity. (B) Per-layer
pass@k AUC (no min over layers) on two eval sets — `multihop` and `typo` — for three transports:
`logit` (J = I), `jlens` (the fitted operator), and `shuffled` (the fitted operator with its layer
index permuted by a fixed derangement). The same per-layer curves were then summarised three ways:
best single layer, mean over layers, and min over layers. Prompts were `.rstrip()`-ed before
tokenisation (`experiments/t15_shuffle_diagnostic.py:89`).

## PRE-REGISTERED RULE (verbatim)
No numeric decision rule is stored in the results file (no `decision_rule` key). The file stores two
named hypotheses, `results/t15_shuffle_diagnostic_410m.json -> hypotheses`:

> "H_SIM": "Jacobians are near-identical across layers, so shuffling is a no-op"
> "H_MIN": "min-over-layers launders the difference; per-layer, jlens should beat shuffled almost everywhere"

The script docstring states the same two hypotheses with their predictions,
`experiments/t15_shuffle_diagnostic.py` docstring:

> H-SIM  "The Jacobians are nearly identical across layers, so shuffling is close to a no-op."
>        Predicts: high pairwise cos(J_i, J_j); shuffled ~ jlens EVERYWHERE, including
>        per-layer.
>
> H-MIN  "pass@k takes a MIN OVER LAYERS, which rewards DIVERSITY among per-layer readouts.
>        Shuffling re-pairs (h_l, J_l') without reducing how many readouts you get, and a more
>        diverse set of readouts can lower the min by chance."
>        Predicts: per-layer, jlens BEATS shuffled almost everywhere; the shuffled advantage
>        exists only after the min is taken. **That would make it a metric artifact, not a
>        property of the lens.**

Registration source: the script docstring only (`experiments/t15_shuffle_diagnostic.py`). No file in
`docs/archive/prereg/` covers T15. The docstring ends "EXPLORATORY."
