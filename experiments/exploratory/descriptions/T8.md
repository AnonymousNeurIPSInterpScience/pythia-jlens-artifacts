# T8 — write battery on the anchor's probe-swap set at pythia-410m

## WHAT WAS RUN

`experiments/t8_probe_swap.py` loaded the 90 items of `jacobian-lens/data/experiments/probe-swap.json`
(vendored at `581d398`) and, for each item, attempted a band-wide activation write that replaces the
`intermediate` representation with `swap_to` across layers 9–22 at every prompt token position except
the first. Items were filtered by two gates before scoring: a surface-form gate (the
`intermediate`/`swap_to` and `answer`/`swap_answer` pairs must each resolve to distinct single tokens
under a common surface form) and a baseline gate (greedy next token must equal `answer`). Each
surviving cell was run under five arms — `identity`, `swap@a1`, `rand_target@a1`, `orth@a1`,
`oracle@a1` — and the next token at the final position was scored against `swap_answer`. A per-dose
oracle gate then decided admissibility: a cell counts at α only if the answer-token oracle flips at
that same α.
