# T14B — what layer-0 Jacobian dispersion co-varies with across six Pythia models

## WHAT WAS RUN

For the same six penultimate-target lenses used by T14, the layer-0 dispersion value was tabulated
alongside each model's layer count, hidden width and parameter count, and log-log Pearson
correlations of `disp_layer0` against each of the three were stored, together with a fitted power-law
exponent against depth. The file also stores a prose identification of the discriminating pair of
models and a correction relative to the earlier three-model version of T14.
