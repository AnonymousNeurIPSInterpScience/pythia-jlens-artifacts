# `experiments/exploratory/` — Arc 1, retained for provenance

These scripts and their descriptions are a **prior research arc**. They are **not part of the
paper**: no result they produce is cited, and none is named in the experiment register
(`docs/experiments/INDEX.md`).

They are retained rather than deleted for one reason. Several of their results files are still
present in the artifact mirror. A results file
whose producing script has vanished looks worse than a script in a clearly-labelled directory.

**Nothing here is maintained.** Some of it predates the corrected readout (see
the readout correction described in `docs/context/CONTEXT.md`) and the `min`-primary aggregation convention (see
`docs/context/AGGREGATION_POLICY.md`), so numbers it emits will not match the paper's conventions.
Read `descriptions/` for what each one was for.

The experiment numbering the paper uses (E28, E33, E36, …) continues this arc's numbering, which is
why the paper's series appears to start partway through.
